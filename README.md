# 《摸鱼：我的小说首富成真了》

> 白天给老板写代码，晚上给世界写剧本——键盘才是我最大的金手指。

## 作品简介

| 项目 | 内容 |
|------|------|
| **题材** | 打脸爽文 · 都市幻想 · 职场逆袭 · 系统流 · 扮猪吃虎 |
| **平台** | 番茄小说 |
| **体量** | 200 章，每章约 2000 字，总计约 40 万字 |
| **读者画像** | 25–35 岁男性职场人，渴望逆袭与代偿性爽感 |

**一句话卖点：** 28 岁大厂"007"后端程序员陈默，发现自己写在番茄小说里的剧情会变成现实。从此他一边摸鱼一边用键盘改写世界，从废柴码农一路躺成全球首富。

## 核心设定约束

以下规则是整部张力的来源，创作时**必须严格遵守**：

1. **不能直接写死任何人**
2. **不能改变已发生的重大历史事件**
3. **写作到现实生效有 3–24 小时延迟**（制造紧迫感）
4. **每约 15 章安排一次"能力失控"**（如写错字引发连锁灾难）
5. **主角直到第 180 章才完全理解能力来源**

## 情绪节奏

每 **3 章** 构成一个完整情绪单元，遵循 **"压 → 小扬 → 压 → 爆"** 循环：

- **压**：职场憋屈、被甩锅、被威胁
- **小扬**：小说改写生效，小范围翻盘
- **压**：胜利引发更大危机
- **爆**：高潮反转，全场打脸

单章内部（2000 字）按 7 段式结构推进，每约 300 字设置一个情绪拐点。详见 `大纲.md` 与 `CLAUDE.md`。
