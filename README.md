# 《摸鱼：我的小说首富成真了》

## 这是什么

一个 **AI 辅助网文创作**项目。

用 AI（Claude Code）辅助写网络小说，发布到番茄小说平台，目标是获得稳定稿费收入。同时跑通一套可复用的"AI 写网文"工作流，方便复制到后续作品。

## 仓库内容

本仓库只包含公开内容：

```
.
├── .gitignore          # 忽略本地私有文件
├── README.md           # 本文件
└── content/            # 小说正文（公开部分）
    └── 第一章.txt
```

以下内容**不推送到远程**，仅保存在本地：

- `大纲.md` — 完整创作大纲（剧情、人物、悬念线等核心资产）
- `CLAUDE.md` — AI 协作指令

## 关于本小说

| 项目 | 内容 |
|------|------|
| **题材** | 打脸爽文 · 都市幻想 · 职场逆袭 · 扮猪吃虎 |
| **发布平台** | 番茄小说 |
| **读者画像** | 25–35 岁男性职场人 |

## 为什么用 AI 写

网文的核心是**稳定更新 + 情绪节奏**。AI 负责按模板批量产出、严格执行节奏曲线、管理设定一致性；人负责创意和决策。
