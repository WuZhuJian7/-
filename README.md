# 《摸鱼：我的小说首富成真了》

## 这是什么

一个 **AI 辅助网文创作**项目。

用 AI（Claude Code）辅助写网络小说，发布到番茄小说平台，目标是获得稳定稿费收入。同时跑通一套可复用的"AI 写网文"工作流，方便复制到后续作品。

## 仓库内容

本仓库只包含公开内容：

```
.
├── .gitignore          # 忽略本地私有文件
├── README.md           # 本文件
└── content/            # 小说正文（公开部分），按钩子弧分文件夹
    ├── 1-3/ 4-5/ 6-14/ 15/ 16-21/ 22-23/   # 已发布 1–23 章，锁定
    └── (24+ 按新钩子弧建文件夹)
```

以下内容**不推送到远程**，仅保存在本地：

- `大纲.md` — 完整创作大纲（含「执行校正与续写方向」段）
- `CLAUDE.md` — AI 协作指令
- `.learnings/` — 连载一致性工作记忆（AI 写章前必读，守护不穿帮）：
  - `STORY_BIBLE.md` 事实源（10 条能力规则 / 8 悬念线 / 硬红线 / 命名合规 / 存储约定）
  - `CHARACTERS.md` 角色状态 ｜ `PLOT_POINTS.md` 进度+断线排期 ｜ `LOCATIONS.md` 地点
  - `钩子索引.md` 钩子弧文件夹索引 ｜ `续写路线图.md` 24–45 章级计划
  - `ERRORS.md` 生成问题+避坑清单 ｜ `关键情节图解.md` Mermaid 人物/势力/悬念图

## 为什么用 AI 写

网文的核心是**稳定更新 + 情绪节奏**。AI 负责按模板批量产出、严格执行节奏曲线、管理设定一致性；人负责创意和决策。
